Uses

A look at the systems, servers and software I use daily to build things, run infrastructure, and keep my projects online.

Operating System

Arch Linux

I use Arch, btw. The rolling release model, minimalism and total control over the environment make it the perfect base for a server admin and tinkerer.

Servers & Infrastructure

Pterodactyl

My panel of choice for managing game servers. It keeps deployment, per-server resources and user access tidy and automated.

Proxmox

Virtualization backbone. I run containers and VMs on Proxmox to keep services isolated and easy to snapshot and rebuild.

Docker & Nginx

Docker for packaging services, Nginx for reverse proxying and serving. Together they make deploying and scaling painless.

Security & Networking

Cloudflare

DNS, WAF and DDoS mitigation sit in front of everything. It's the first line of defence for my servers and domains.

iptables / nftables / UFW + Fail2Ban

Host-level firewalling and brute-force protection, hardened with my own AntiDDoS-Beta script.

Development & Bots

VS Code

My go-to editor for building websites, bots and scripts, always customised for speed and clarity.

Discord.js

I build and run Discord bots — from community tooling to automation for the servers I manage.

Minecraft Stack

Paper / Purpur with BungeeCord, plus Geyser + Floodgate so Bedrock players can join Java servers.
