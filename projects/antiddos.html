AntiDDoS-Beta

Hosting a server shouldn't mean praying it survives the next flood. AntiDDoS-Beta is a safe firewall management script that shields Linux servers from DDoS, SYN floods, port scans and SSH brute-force attacks — without locking out the ports your hosting actually needs.

Why I Built It

Running game and web servers means dealing with constant abuse — SYN floods, port scans, and endless SSH brute-force attempts. Most hardening guides either leave you exposed or break your hosting ports. I wanted a single script that hardens a server properly while keeping HTTP/HTTPS, FTP, SMTP, MySQL and DNS open and functional.

Core Features

Anti-DDoS Protection

SYN flood protection with ICMP rate limiting, tuned to stay safe for live hosting.

SSH Brute-force Protection

Rate-limits login attempts and logs suspicious activity so you can see who is knocking.

Port Scan Protection

Blocks NULL, XMAS and other stealth scans before they can map your services.

Hosting-Friendly

HTTP/HTTPS, FTP, SMTP, MySQL and DNS ports remain open — no broken services.

Safe Uninstall

Flush the rules and restore your previous firewall state with a single command.

Tech Stack Breakdown

  • Language: Shell (bash) — no dependencies beyond the tools already on a Linux server.
  • Firewall: iptables / nftables rules applied safely and idempotently.
  • Targets: Linux servers, especially Debian/Ubuntu based hosting machines.
  • Repository: github.com/anshalmanoj/AntiDDoS-Beta

Looking Forward

The beta is already protecting real servers. Next up is hardening the rules further, adding Cloudflare-aware allow-lists, and shipping a one-line installer so anyone can secure a fresh box in seconds.
